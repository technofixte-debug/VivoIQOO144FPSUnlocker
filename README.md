A specially fork for Oppo, OnePlus, and Realme devices.

It enables the maximum screen refresh rate by changing the "peak_refresh_rate" key to "1"—a tweak that exploits a system glitch to force the highest refresh rate. It also allows you to add a toggle to the Control Center (quick settings panel) so you can enable the maximum refresh rate in just two taps at any time.
It does not work on all devices; if it doesn't work for you, please do not message me! You might want to look for an alternative, but this unlocker is confirmed to work on the Realme GT/Neo series and the OnePlus Ace series (though functionality may be partial on some models); it should also work on Oppo devices, though I haven't tested it myself.
