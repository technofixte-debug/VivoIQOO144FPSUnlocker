специально изменённое приложение для oppo/oneplus/realme
включает максимальную частоту обновления экрана через смену ключа "peak_refresh_rate" на значение "1" из-за этого система багается и включает максимальную частоту обновления экрана, также есть возможность поставить плитку в центре управления (шторке) чтобы в любое время за два клика включать максимальную частоту обновления экрана.
